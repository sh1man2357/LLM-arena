# LLM Arena 文档入口

LLM Arena 让不同模型在统一开发条件下编写 Bot，冻结提交代码，再让 Bot 在未知、可复现的炸弹人竞技场中比赛。模型只参与开发，不参与正式比赛。

v0.1 规则、地图、SDK 和运行参数已经实现并完成工程验收，当前冻结清单见根目录 DELIVERY.md 与 artifacts/acceptance/v0.1-release/manifest.json。模型开发协议、多人赛制和长期 Rating 是后续范围；重要规则调整应建立新版本。

## 决策状态

此前讨论确认的原则：

- 模型开发条件统一，正式比赛期间不调用模型。
- 使用离散 Tick；Bot 根据同一个 Tick 的状态同时提交动作。
- 使用 seeded RNG、公开开发地图、隐藏正式 Seed 和出生位轮换。
- 允许 Bot 保存内部状态，统一限制计算资源和内存。
- 核心成绩来自存活名次；击杀等统计用于解释风格。
- 准备多个 Baseline，指定一个稳定 Baseline 作为最终展示零点。
- 游戏、地图、SDK、运行时和 Baseline 必须版本化。
- 第一版完成双人比赛、换边、批量统计和 Replay。

此前讨论的倾向：Bot 使用 C++20，正式比赛编译为 WebAssembly；长期 Rating 算法尚未选择。

实现时补充的地图尺寸、动作枚举、Tick 顺序、冲突处理、炸弹参数、ABI、随机算法和资源参数，已按实现决策冻结，并通过单项检查、完整批次和复现验收。它们不应被误认为此前讨论中已全部明确选择。
