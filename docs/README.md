# LLM Arena 文档入口

LLM Arena 让不同模型在统一开发条件下编写 Bot，冻结提交代码，再让 Bot 在未知、可复现的炸弹人竞技场中比赛。模型只参与开发，不参与正式比赛。

这些文档是实现前的设计草案，不表示项目已经具备其中描述的功能。正文中标为“规范”的内容是本草案内部必须一致遵守的约束；整个 v0.1 草案仍可在实现前调整。

## 决策状态

此前讨论确认的原则：

- 模型开发条件统一，正式比赛期间不调用模型。
- 使用离散 Tick；Bot 根据同一个 Tick 的状态同时提交动作。
- 使用 seeded RNG、公开开发地图、隐藏正式 Seed 和出生位轮换。
- 允许 Bot 保存内部状态，统一限制计算资源和内存。
- 核心成绩来自存活名次；击杀等统计用于解释风格。
- 准备多个 Baseline，指定一个稳定 Baseline 作为最终展示零点。
- 游戏、地图、SDK、运行时和 Baseline 必须版本化。
- 第一版完成双人比赛、换边、批量统计和 Replay。

此前讨论的倾向：Bot 使用 C++20，正式比赛编译为 WebAssembly；长期 Rating 算法尚未选择。

本次为实现补充的建议：地图尺寸、动作枚举、Tick 顺序、冲突处理、炸弹参数、ABI、随机算法和资源参数。它们在各文档中具体定义，但不应被误认为已经通过实验校准或此前全部获得确认。

## 建议默认配置

| 参数 | v0.1 建议值 | 定义位置 |
| --- | --- | --- |
| 比赛人数 | 2；协议预留最多 8 | 游戏规则、SDK |
| 地图 | 13 × 11，180° 对称 | 地图规范 |
| 初始炸弹容量 / 范围 | 1 / 3 | 游戏规则 |
| 炸弹延迟 | 放置 Tick + 4 时爆炸 | 游戏规则 |
| 最大 Tick 数 | 500 | 游戏规则 |
| WASM 内存上限 | 64 MiB | SDK |
| 每 Tick fuel / 初始化 fuel | 1,000,000 / 10,000,000，待校准 | SDK |
| 连续 / 累计动作故障淘汰阈值 | 3 / 20 | SDK |
| 开发 / 正式地图数 | 10 / 50；双人正式共 100 局 | 评测规范 |

实现前仍需确定具体 WASM 运行时、固定编译工具链和 fuel 校准结果。这些选择必须写入运行清单。v0.1 先输出胜负平与名次分，不伪造尚未实现的长期 Rating。
