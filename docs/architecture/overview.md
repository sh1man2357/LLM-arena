# 核心架构

比赛核心使用 Python 3.12、Wasmtime 49.0.0 和 WASI SDK 33.0。C++20 源码通过统一 SDK 和编译参数生成 WASM；规则引擎只使用整数 Tick，观众播放速度不进入结算。

| 模块 | 职责 |
| --- | --- |
| `engine/` | 纯规则、地图、同时移动、爆炸与终局 |
| `sdk/`、`runtime/` | C++ 接口、ABI、沙箱、fuel 与故障分类 |
| `runner/` | 编译、资格、单局、固定赛程与报告 |
| `replay/` | 世界回放、Bot 重跑和文本观赛 |
| `service/` | 收卷、持久作业、索引、直播、发布与恢复 |
| `web/` | 已确认帧的图形观赛与主办方工作台 |

每个 Tick 给所有 Bot 同一快照，收齐动作后统一结算。运行时返回动作或故障，不能修改世界。CLI 与本地服务共用编译、资格、比赛和报告实现。

## 冻结与复现

源码、WASM、SDK、工具链、规则、资源预算和地图 / Bot Seed 共同决定输入。manifest 保存组件哈希、参赛者与赛程；Replay 保存初始状态、初始化结果、动作、调用、事件、逐 Tick 世界和终局。

世界验证重新执行规则并比对状态、事件和结果；Bot 重跑另需对应 WASM 与环境，重新核对动作和故障。报告从固定赛程和已验证 Replay 汇总，缺失或基础设施失败的批次标为 incomplete，不给出正式排名。

恢复赛程会核对冻结输入和已完成 Replay，避免重复计分。失败重试保存旧尝试，规则或源码变化后使用新批次。数据格式与规则编号属于复现契约。

## 直播与参考赛

单局通过记录观察接口逐 Tick 输出完整结算帧，服务持久写入后提供帧游标。浏览器断连、回看与变速不影响计算，详见[本地服务](service.md)。

工程参考赛由 `service/reference.py` 从当前三个基准源码和公开工程地图生成。连锁演示来自 `bots/examples/`。首次启动无需历史归档或 Git 历史，生成数据进入本机实例或忽略的测试目录。

运行见[CLI](../guides/cli.md)与[开发指南](../guides/development.md)，接口见[SDK](../specs/bot-sdk.md)。
