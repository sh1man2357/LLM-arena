# 前端体验与视觉规范

界面只保留首页、观赛和榜单；使用同一顶部导航与视觉 tokens。以棋盘和主要操作为中心，减少管理表单和技术信息。

## 页面

| 页面 | 内容 |
| --- | --- |
| 首页 | 优先展示双方选择和运行；折叠 .cpp 导入与名称、Bot 状态、可选地图 Seed、运行记录 |
| 观赛 | 双方名称 / 存活 / 必要故障、棋盘、时间轴、播放控制、结果 |
| 榜单 | 同分并列名次、Bot、局数、胜 / 平 / 负、平均得分；统计口径折叠在计分规则中 |

不提供批次、参赛者详情、收卷、管理工作台、发布或备份页面。编译失败在 Bot 列表就地展示，日志可展开。运行记录直接进入观赛，分页只用于访问较旧记录。

## 统一播放器

`Viewer.tsx` 只根据运行状态和连续帧工作；没有独立直播 / 录像组件。服务端负责游戏逻辑，Canvas 仅呈现事实。

- 运行中默认跟随最新；暂停、拖动、单步或播放切换为回看。
- 回到最新恢复跟随；没有新帧时等待，不生成预测帧。
- 已结束录像初始停在第 0 帧，播放到尾停止；可重新从头播放。
- 支持首尾定位、五档倍速、全屏和基本快捷键。
- 运行结束显示结果；失败 / 中断明确说明本局不计分，保存帧仍可回看。
- 重新运行创建独立记录，不能在旧录像里混入另一轮帧。

初始帧与结算 Tick 语义一致，0 Tick 可展示。动画只连接已确认起终点；爆炸覆盖来自适配器。两种墙、双方和脚下炸弹可辨认；双方使用编号、不同形状和固定槽位颜色，不能只靠颜色。

## 视觉与窄屏

视觉参考 [ARC-AGI-2](https://arcprize.org/arc-agi/2)：近黑背景、暖灰正文、黄色主操作、细分隔线和留白。首页按新对局、Bot、对局记录排列；区块采用平面布局。顶部只保留品牌与对战 / 榜单切换，不增加侧栏。

界面文本只保留名称、动作、状态、错误与必要数据。移除宣传副标题、英文区块编号、页内重复导航、基准角标、常驻连接小字和页脚；连接异常时才显示提示。Bot 导入、地图设置、编译日志和榜单计分规则默认折叠。操作使用 [Lucide React](https://lucide.dev/guide/react) 图标，版本锁定在 package.json 与 package-lock.json；图标按需导入，不依赖外部字体或 CDN。纯图标按钮具备 aria-label 与 title，图标本身不重复朗读。

棋盘与页面共用 `tokens.css`：底色与地面为中性黑灰，固定墙为实心灰块，可破坏墙为深灰底与虚线边框。移除砖纹、倒角、阴影、双色地砖和地面装饰点。玩家 0 为白色圆形，玩家 1 为黄色菱形，均保留编号；炸弹为所有者颜色的轮廓与倒计时，爆炸覆盖为半透明黄色与细十字。脚下炸弹、淘汰状态及已确认移动仍沿用真实运行帧。

观赛页去掉常驻坐标与重复播放模式文案；播放定位与倍速 / 全屏分组，回到最新按钮的按下状态表示跟随直播。榜单直接展示表格，胜 / 平 / 负合并为一列。

区块在窄屏改单列，双方选择仍并排，播放控制分行；长 Bot 名称和日志可换行，表格在自身容器内滚动。操作触控目标至少 44px，焦点可见；折叠区支持键盘，输入控件聚焦时不抢占快捷键。Canvas 外有 DOM 双方状态，动画支持减少动效。字体使用系统字体。

## 核心走查

使用专用测试实例检查：无数据、编译中 / 失败 / 成功、运行准备、直播、回看、等待帧、断连、完成、初始化结束、失败 / 中断和空榜单。

桌面与 390px 窄屏检查棋盘辨认、操作可达、长名称、横向溢出、键盘与全屏。浏览器脚本和截图输出到 Git 忽略目录。构建通过不代替对真实运行画面的检查。
