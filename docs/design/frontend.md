# 前端界面规范

| 页面 | 路由 | 主要操作 |
| --- | --- | --- |
| 对战 | `/` | 选择游戏、模式、参赛槽位和开局条件，开始对战。显示当前运行入口及所选游戏最近完成的五条录像 |
| 录像 | `/history` | 搜索、筛选、重命名、回看、移入回收站或恢复记录 |
| Bot 库 | `/bots` | 按游戏下载任务包、复制提示词、导入源码，查看编译结果并管理 Bot |
| 榜单 | `/leaderboard` | 按游戏查看实力分、参赛次数和得分。五子棋另列执黑、执白得分 |
| 观赛 | `/matches/:id` | 显示棋盘、参赛状态、事件、播放控制与结果。人机对局在当前棋盘接受落子 |

游戏选择保存在当前浏览器会话。基准身份与显示名称独立，改名后仍显示基准标记。任务包下载与源码导入共用当前游戏选择。复制提示词失败时显示可选取的完整文本。

## 播放与布局

`Viewer.tsx` 使用服务端已确认的帧。运行中的 Bot 对战顺序播放，已结束的录像从第 0 帧暂停。暂停、单步、拖动、倍速和全屏均在浏览器内生效。「回到最新」定位到最新已接收帧。人机对局进行中显示最新棋盘、落子提示和认输操作。

桌面观赛页将棋盘与播放控件置于左侧，参赛状态与事件置于右侧。棋盘按可用宽高等比缩放，为控件预留空间。窄屏采用纵向布局，低高度横屏可将播放控件移到棋盘旁。炸弹人时间轴标记击杀帧；五子棋显示上一手、可选手数和获胜连线。

## 交互约定

- 使用 `tokens.css` 定义颜色和字体。炸弹人槽位以编号、颜色及形状区分；五子棋以黑白棋子表示棋色。
- 图标按钮提供可访问名称，键盘焦点可见。折叠区可用键盘展开，表单输入期间避免触发播放器快捷键。
- 编译诊断靠近对应 Bot，连接和操作错误在所在页面显示。浏览器验证使用[独立测试实例](../guides/development.md)。
