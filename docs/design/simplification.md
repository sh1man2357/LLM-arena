# 设计记录：本地对战与录像

2026-10-10 的简化改造将主流程收敛为源码导入、Bot 对战、实时观看和录像回看。本文保留当时的设计决策。当前的游戏模式、页面与接口分别见[项目概览](../project.md)、[前端规范](frontend.md)和[服务架构](../architecture/service.md)。

| 决策 | 理由 |
| --- | --- |
| 将编译和资格检查并入 Bot 导入 | 每次导入形成可追溯的程序快照，参赛选择直接引用快照 ID |
| 以对局为录像单位 | 实时观看和历史回看读取同一条顺序记录，播放速度和暂停操作仅影响当前浏览器 |
| 每个数据目录只执行一个计算任务 | 编译与对局共享本机计算资源，忙时拒绝新的计算请求 |
| 从已验证的本机记录计算榜单 | 回收站、恢复和结果有效性直接决定统计范围 |
| 移除收卷会话、批次赛程、封存发布和备份管理页面 | 程序开发由参赛方完成，对战与回看在本机进行。既有主办方数据保留 |

后续版本增加了五子棋换色对战和人机单盘。换色属于一次 Bot 对战的执行规则，两盘分别保存录像。
