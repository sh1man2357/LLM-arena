# 文档维护

## 内容归属

| 位置 | 维护内容 |
| --- | --- |
| 根目录 `README.md` | 项目简介、快速启动、主要阅读入口 |
| 根目录 `MODEL_TASK.md` | 直接分发给模型的完整任务协议 |
| `docs/README.md` | 按用途索引全部文档 |
| `docs/guides/` | 可执行的操作步骤与运行限制 |
| `docs/specs/` | 游戏、接口、地图与评分的精确契约 |
| `docs/architecture/` | 模块、服务与实现决策历史 |
| `docs/design/` | 产品范围、设计标准与历史规划 |
| `docs/releases/` | 版本交付状态、逐项验收与交接 |
| `docs/records/` | 有时间范围的检查、评审和分析记录 |

新增文档用内容命名，不加连续编号。先补充已有主题文档，再考虑新增文件；在[文档目录](./README.md)登记入口。代码示例注明执行目录，文件引用优先使用相对 Markdown 链接。

项目完成状态在版本交付清单更新。规格和指南引用清单，不另维护一套进度；历史记录保留当时的检查数量、失败记录和未完成项，并明确其时间范围。

## 检查

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe tools\check_docs.py --links-only
# 包括冻结 v0.1 源码、归档哈希与交付清单的完整检查
.\.venv\Scripts\python.exe tools\check_docs.py
```

文档检查递归覆盖文档目录和根目录任务书，核对本地链接与代码围栏。修改文档路径时同步维护引用它们的工具。
