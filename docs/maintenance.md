# 文档维护

| 位置 | 维护内容 | 核对依据 |
| --- | --- | --- |
| 根目录 `README.md` | 项目用途、启动方式和主要入口 | 启动脚本、当前界面 |
| `docs/guides/` | 面向使用者的操作步骤 | PowerShell 参数、CLI 帮助、页面控件 |
| `docs/specs/` | 规则、二进制协议、资源限制与计分 | 规则引擎、SDK、运行时、榜单计算及测试 |
| `docs/architecture/`、`docs/design/` | 模块、数据流、接口、界面约定和历史决策 | 服务路由、存储、前端组件及版本历史 |
| `devkit/` | 按游戏分发的执行入口和任务书 | 打包清单、根目录入口、SDK 头文件及练习工具 |

同一主题优先更新原文，在[文档目录](README.md)维护入口。使用实际控件名称、命令和相对链接。命令须注明工作目录和必要前置条件；涉及种子或开局时，应区分应用、CLI 和练习工具的默认值。历史记录应标明日期。

在仓库根目录运行 `.\.venv\Scripts\python.exe tools\check_docs.py`，检查根目录文档、指南、规格和任务材料的本地链接与代码围栏。该检查不验证参数、规则或运行结果。修改任务书后还应生成两份 ZIP，核对根目录入口、对应游戏及内嵌 SDK。
