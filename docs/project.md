# 项目概览

LLM Arena 是本地双人炸弹人 Bot 对战与观赛工具，主流程为：导入 Bot → 选择双方 → 运行一局 → 观看与回看。

首页提供 Bot 导入和运行记录，观赛页共用一个播放器处理不断增长的实时记录和已结束录像。榜单暂时保留，汇总本机已验证有效单局，不提供统一赛程或长期评级。

## 范围

保留规则引擎、地图、SDK、C++20 编译、WASM 沙箱、三个基准 Bot、单局执行、录像与世界校验，以及本地应用。开发包提供模型编写 Bot 所需的公开材料和可选练习工具。

已移除收卷 / 开发计时、正式提交档案、批次 / 自动全配对、详细成绩分析、封存 / 发布、归档导入、公开导出和私有备份恢复业务。多人玩法、云账号和自动模型 API 编排不在范围内。

## 固定规则

| 参数 | 值 |
| --- | --- |
| 人数 / 地图 | 2 人；13 × 11，180° 对称 |
| 动作 | 等待、四方向移动、放炸弹 |
| 炸弹容量 / 范围 | 1 / 3 |
| 炸弹到期 | 放置 Tick + 4 |
| 最大结算次数 | 500 Tick |
| WASM 内存 | 64 MiB |
| 每 Tick / 初始化 fuel | 1,000,000 / 10,000,000 |
| 连续 / 累计动作故障阈值 | 3 / 20 |

服务端按整数 Tick 结算，所有 Bot 同时获得同一快照。浏览器呈现已确认帧，播放控制不改变世界。精确行为见[规则](specs/rules.md)、[SDK](specs/bot-sdk.md)和[地图](specs/maps-and-randomness.md)。

## 目录和数据

| 目录 | 职责 |
| --- | --- |
| `engine/` | 规则、地图、移动、爆炸、终局 |
| `sdk/`、`runtime/` | C++ 接口、ABI、沙箱与计算限制 |
| `runner/`、`replay/` | 编译、单局、轨迹、校验、文本观看 |
| `service/` | Bot 快照、单计算任务、运行记录、帧接口、榜单 |
| `web/` | 首页、观赛、榜单 |
| `bots/baselines/` | Random、Safe、Heuristic |
| `devkit/` | 开发任务材料，ZIP 根目录执行入口 |
| `configs/`、`tools/`、`tests/` | 固定配置、安装 / 开发工具、核心验证 |
| `artifacts/` | 本机数据、测试输出和任务 ZIP，Git 忽略 |
| `.venv/`、`.tools/`、`web/node_modules/` | 本机依赖，Git 忽略 |

每次导入形成独立 Bot，运行保存 Bot 产物、随机输入和版本。源码更改后重新导入，旧录像不会随新 Bot 改变。旧版主办方数据保留，不自动映射到新版 Bot / 运行记录。维护使用当前源码生成样例，保留 Git 历史。
