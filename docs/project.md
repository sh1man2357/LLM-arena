# 项目概览

LLM Arena 比较模型在统一开发协议下生成有效策略程序的能力。模型收到同一任务书，在 60 分钟内提交 C++20 Bot；提交冻结后，程序在隐藏地图和相同资源限制下参加双人炸弹人比赛。

流程为：任务分发 → 源码冻结 → 编译与资格检查 → 隐藏地图换边比赛 → 直播 / 回放 → 报告与证据发布。模型参与开发，正式比赛执行冻结程序。

观赛让人能直观看到 Bot 的行动，定位关键时刻，并理解成绩依据。一次提交的成绩受生成波动、语言熟练度和工具使用影响，不能完整代表模型的全部能力。

## 默认对局配置

| 参数 | 冻结值 |
| --- | --- |
| 人数与地图 | 2 人；13 × 11，180° 对称 |
| 动作 | 等待、四方向移动、放炸弹 |
| 炸弹容量 / 范围 | 1 / 3 |
| 炸弹到期 | 放置 Tick + 4 |
| 最大结算次数 | 500 Tick |
| WASM 内存上限 | 64 MiB |
| 每 Tick / 初始化 fuel | 1,000,000 / 10,000,000 |
| 连续 / 累计动作故障阈值 | 3 / 20 |

最后存活者获胜；达到上限时存活者并列。精确行为以[规则](./specs/rules.md)、[SDK](./specs/bot-sdk.md)、[地图](./specs/maps-and-randomness.md)和[评测规格](./specs/benchmark.md)为准。

| 目录 | 职责 |
| --- | --- |
| `engine/` | 纯整数规则结算与地图生成 |
| `sdk/`、`runtime/` | C++ 接口、统一编译包装、WASM 执行和预算 |
| `runner/`、`replay/` | 编译、赛程、报告、轨迹写入与复现校验 |
| `service/` | FastAPI 本地服务、SQLite 索引与独立 worker |
| `web/` | React / TypeScript 观赛与管理界面 |
| `bots/baselines/` | Random、Safe、Heuristic 参考策略 |
| `configs/`、`tools/`、`tests/` | 冻结配置、安装 / 验证工具与行为检查 |
| `artifacts/acceptance/` | 已冻结的验收证据、报告、索引与归档 |
| `artifacts/local/`、`artifacts/work/` | 本机服务数据与临时产物，Git 忽略 |

| `docs/` | 使用、规格、架构、设计、交付与历史记录 |

## 维护原则

规则先于策略冻结，不按某个 Bot 的成绩临时调整。所有 Bot 读取同一 Tick 的公共状态，同时提交动作；模拟使用整数 Tick，观众播放速度不进入结算。

源码、WASM、SDK、工具链、运行参数和地图版本共同构成成绩依据，保留配置与哈希。规则变化须建立新版本并重新验收；批次排名只描述相同对手池，不能当作跨版本长期评级。
