## 1. 交付目标与规格

交付一套风格统一、视觉完成度高、交互完整的本地观赛产品。用户可以从浏览器收卷、组织比赛、观看真实对局、逐 Tick 回放并解释成绩；已有确定性与可审计证据完整保留。

本版主题为“可观赛、可解释、可交接”。前端是主要产品成果；配套开发按收卷资格、赛事组织 / 直播、结果解释、故障恢复、证据分发 / 数据迁移、安装交接六组安排，优先打通真实路径，再补齐发布前的可靠性与质量验证。各组的复用基础、投入优先级和观赛价值见 [开发安排](../design/v0.2-plan.md)。

首轮产品评审以“大厅 → 真实观赛 → 关键事件 → 换边 → 批次解释”为完整演示路径；优先打磨观赛页与大厅，再扩展其余页面和异常状态。可手工指定真实代表性对局，不以自动集锦为前提；工程参考赛明确标注 Baseline，不冒充模型展示赛。具体默认行为及设计评审顺序见 [前端规范](../design/frontend.md)。
