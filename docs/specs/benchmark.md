# 对局得分与榜单实力分

榜单按游戏、Bot 快照 ID 和本机有效对局计算。显示名称可以修改，程序重新导入后使用新 ID。

## 单局得分

| 指标 | 炸弹人 | 五子棋 |
| --- | --- | --- |
| 局内排名 | 规则 2 按总积分排序。每回合结算后存活得 1 分，每击杀一名对手得 100 分，同分并列 | 每盘胜、平、负分别得 1、0.5、0 分 |
| 名次分 | `(积分较低的对手数 + 0.5 × 同分对手数) / (人数 − 1)` | 等于该盘得分 |
| 胜、平、负 | 独占第一记胜，并列第一记平，其余记负 | 按每盘结果统计 |
| 平均得分 | 累计名次分除以参赛槽位数 | 累计得分除以参赛槽位数，另列执黑、执白平均分 |

多人局并列第一时，名次分可能高于 0.5。重复使用同一 Bot 时，各槽位分别累计参赛与得分；两槽位间的自我对战不给该快照增加实力比较证据。规则见[炸弹人](rules.md)及[五子棋](gomoku.md)。

## 纳入条件

- 对局未移入回收站，状态为 `completed`，已通过世界校验且结果标记为有效。服务还校验槽位、得分范围及分数和（人数的一半）。
- 炸弹人只统计终局标记 `scoring_version = 2` 的对局。旧规则录像可以回看和重赛。
- 五子棋只统计完整的 Bot 换色组。两盘须属于同一任务并正确关联，开局和种子一致、参赛顺序互换，且两盘均满足有效性条件。人机单盘不计入榜单。
- 删除对局后重新计算；删除五子棋组中任一盘使整组退出统计。删除 Bot 隐藏其榜单行，其有效历史对局仍可用于估计其他选手的实力。

## 实力分

当前基准 Bot 的实力分固定为 0。计算采用锚定的 Bradley–Terry 模型，胜率为 `P(A 胜 B) = 1 / (1 + 10^((R_B − R_A)/400))`。每局按槽位两两比较，胜、平、负分别记 1、0.5、0，每对权重为 `1/(人数 − 1)`。非基准快照在对数胜算尺度上的零均值高斯先验精度为 0.1。

只有与当前基准存在直接或间接对战关系的快照才能估分。基准即使未参赛也显示 0 分；已参赛但未关联基准者显示「待定」，其他未参赛快照不显示。实力分保留两位小数，按显示分降序排名，相同分数并列（如 1、1、3）。

每次读取榜单时根据有效记录重新估计。正负分分别表示高于或低于本游戏当前基准的估计值。不同游戏使用独立的基准和对战数据。
