# 单局得分与本地榜单

项目保留原双人规则的名次分，暂时提供本地榜单。没有限时收卷、隐藏批次、自动全配对、配对矩阵、置信区间报告或长期 Rating。

## 单局

双人胜 1 分、平 0.5 分、负 0 分。存活者优于已死者；双方已死时死亡 Tick 更晚者获胜；同 Tick 死亡平局；Tick 上限仍存活者平局。初始化淘汰使用死亡 Tick −1。

击杀、炸墙和行动次数不额外加分。Bot 故障按规则淘汰后正常参与胜负；宿主 / 写盘 / 引擎失败不产生有效胜负。精确规则见[游戏规则](rules.md)。

## 榜单

只有新版 `run` 记录同时满足以下条件才计入：

- 运行状态为 completed；
- 已完成世界校验；
- 终局结果 valid；
- 双方槽位与得分有效，两个得分之和为 1。

对每个 Bot 快照汇总局数、胜 / 平 / 负和总分，平均得分为 `(胜 + 0.5 × 平) / 有效局数`。按平均得分降序，同分采用并列名次（如 1、1、3）；内部使用精确分数判断并列。未参赛 Bot 不进入排名。

快照 ID 是统计身份，显示名称不是唯一键。槽位交换时仍按 Bot ID 计分。每次成功的重新运行计为独立单局，失败 / 中断不计分；旧版批次不混入。

同一个 Bot 可以同时占据双方槽位，各自使用独立运行实例和 Bot Seed。榜单按两个槽位分别累计参战与得分，有效对局总数仍计一场。

不同 Bot 的对手和局数可能不同；重复相同输入不会增加新的地图证据。这是本机运行统计，不能据此声称统一评测、跨模型全面能力或跨版本长期评级。基准 Bot 是工程参照程序。

内置 Random 随机选择六种动作；Safe 不放炸弹，依据未来 6 Tick 的爆炸预测选择安全动作。Heuristic 沿可通行格计算到软墙或对手的最短路径距离，允许先远离目标再绕墙接近；硬墙和已有炸弹阻断路径。放弹仍须有预期用途并通过逃生检查，不预测对手后续动作。

## 开发与快照

模型开发包提供同一 SDK 和公开材料，生成单文件 `bot.cpp`。主应用直接导入并自动编译检查，不管理模型开发时间或源码收卷。

运行保存 WASM 哈希、规则 / 工具版本、地图 Seed 和 Bot Seed；重新导入源码建立新 Bot，不能覆盖旧快照或沿用旧身份的成绩。规则与资源预算变化须重新验证。
