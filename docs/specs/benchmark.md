# 单局得分与本地榜单

本文件主体描述炸弹人。五子棋使用独立榜单，只统计完整有效的两盘换色对战；每盘胜 1、平 0.5、负 0 分，并显示执黑和执白成绩，详见[五子棋计分与契约](gomoku.md)。

项目支持炸弹人 2～8 人各自为战，以及五子棋双人换色对战。每种游戏内置一个较强 Baseline 基准 BOT，实力分固定为 0；榜单由本地有效比赛估计其他 BOT 的相对实力。

## 单局

规则 2 按局内总积分排名：每回合结算后仍存活 +1 分，每击杀一名敌人 +100 分，同分并列。已死亡者也可能高于存活者。名次分与局内积分是不同指标。

每个槽位的名次分 = `(排名低于自己的对手数 + 0.5 × 与自己并列的对手数) / (参赛人数 - 1)`。双人仍为胜 1 分、平 0.5 分、负 0 分。独占第一记胜，并列第一记平，其余名次记负；并列第一的名次分可能高于 0.5。

击杀计入局内积分，炸墙和行动次数不加分。Bot 故障按规则淘汰后正常参与胜负；宿主 / 写盘 / 引擎失败不产生有效胜负。精确规则见[游戏规则](rules.md)。

## 榜单

只有新版 `run` 记录同时满足以下条件才计入：

- 炸弹人终局标记 `scoring_version = 2`；旧规则记录可回放和重赛，但不进入当前榜单；
- 运行状态为 completed；
- 已完成世界校验；
- 终局结果 valid；
- 2～8 个槽位与得分有效，全部得分之和为参赛人数 / 2。

对每个 BOT 快照汇总局数、胜 / 平 / 负和总分，平均得分为 `累计名次分 / 参战槽位数`。榜单按实力分降序，同分采用并列名次（如 1、1、3）。唯一基准即使尚未参赛也显示 0 分；未参赛的导入 BOT 不进入榜单。

实力分使用锚定 Bradley–Terry 模型：`P(A 胜 B) = 1 / (1 + 10^((R_B-R_A)/400))`。每局按槽位两两比较名次，胜 1、并列 0.5、负 0；每对权重为 `1/(人数-1)`，避免一个八人局等同于七个完整双人局。基准固定 `R=0`，其他快照在 log-odds 单位使用强度为 0.1 的零均值高斯收缩，防止全胜 / 全负样本产生无穷分。

实力分同时考虑对手强度，支持通过对战关系间接关联基准；与当前基准无直接或间接关联的 BOT 显示“待定”，不赋名次。同一快照之间的自我对战没有实力证据。求解结果保留两位小数，以显示精度判断并列。正分表示估计强于基准，负分表示估计弱于基准；样本少时估计向 0 收缩。

每次读取都从有效记录重新估计，删除、恢复、失败排除即时反映到评分，不依赖比赛提交顺序。新基准快照成为新的 0 分参照，未与其关联的旧成绩不会自动获得实力分。炸弹人与五子棋分别建图和估计，不能直接比较两个游戏的分数。

快照 ID 是统计身份，显示名称不是唯一键。槽位交换时仍按 Bot ID 计分。每次成功的重新运行计为独立单局，失败 / 中断不计分；旧版批次不混入。

同一个 Bot 可以占据多个槽位，各自使用独立运行实例和 Bot Seed。榜单按槽位分别累计参战与得分，有效对局总数仍计一场。

不同 Bot 的参赛人数、对手和局数可能不同；重复相同输入不会增加新的地图证据。这是本机运行统计，不能据此声称统一评测、跨模型全面能力或跨版本长期评级。基准 Bot 是工程参照程序。

炸弹人唯一 Baseline 基准使用六 Tick 连锁爆炸预测、按格记录开放时间和爆炸位图、时空前沿搜索、桶式加权最短路及对手潜在放弹预测。拆墙优先打通通往对手的路线；攻击比较对方放弹前后的逃生空间，并推演一至两步后的拐角放弹。多人局降低追击权重，保留机动空间，优先抓明确的攻击机会。已知爆炸可封住唯一出口时，优先安全占位；占位必须在现有和预测爆炸中均安全。放弹同时检查真实炸弹状态和假设对手放弹的状态，必须能逃生，避免逃生路径依赖穿过对手。搜索按地图大小校准工作预算，前沿截断只能产生保守判断，不能作为无路可逃的证明；完成一个候选方案后才更新动作，给收尾留出余量。已确定的成杀或有效拆墙可提前返回，不为耗尽 fuel 做无效计算。五子棋基准见[五子棋规格](gomoku.md)。旧策略源码仅保留为回归对手，应用和公开开发包不再提供多个内置选手。

## 开发与快照

模型开发包提供同一 SDK 和公开材料，生成单文件 `bot.cpp`。主应用直接导入并自动编译检查，不管理模型开发时间或源码收卷。

运行保存 WASM 哈希、规则 / 工具版本、地图 Seed 和 Bot Seed；重新导入源码建立新 Bot，不能覆盖旧快照或沿用旧身份的成绩。规则与资源预算变化须重新验证。
