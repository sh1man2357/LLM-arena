# 自由五子棋规则与运行契约

游戏 ID 为 `gomoku`，规则版本为 1。15 × 15 棋盘，坐标左上角 `(0,0)`，x 向右、y 向下。槽位 0 执黑、槽位 1 执白，黑先白后，每手在一个空交叉点落子。无禁手；横、竖、两种斜线连续至少五子获胜，长连同样获胜。落子后先检查成五，再检查满盘和棋。

## 开局和终局

应用和 CLI 默认使用空棋盘，均可指定固定三手开局库。公开练习默认使用三手开局库。预置顺序为黑、白、黑，之后白棋行棋。开局库包含三种基础开局各旋转四次，共 12 种；`seed % 3` 选择基础开局，`(seed // 3) % 4` 选择旋转次数。Seed 为 uint32，实际棋盘完全公开。

每步只调用当前行棋方。越界、非法返回、落到已有棋子的位置、超 fuel 或 trap 均立即判本盘负；主动认输同样判负。不允许等待。初始化仅一方失败则该方负，双方失败则平，均保存故障记录。宿主、磁盘、worker 或 watchdog 失败不产生有效胜负。

## Bot SDK

SDK 位于 [gomoku.hpp](../../sdk/gomoku/gomoku.hpp)，只实现 `bot::init(uint64_t)` 与 `bot::tick(const GameState&)`，后者返回 `{x,y}` 或 `Action::resign()`。提交单文件 C++20 `bot.cpp`，包含 `gomoku.hpp`。每盘使用全新实例，静态变量、堆内存和 RNG 可在盘内保留。

状态提供 225 格棋盘（0 空、1 黑、2 白）、自己槽位和颜色、当前行棋颜色、已落子数、上一手、尺寸、成五长度和每步预算。已落子数包含预置三手；空棋盘上一手为 `(-1,-1)`。`init` 接收本槽位的 Bot 种子。观察不含开局种子、对手源码、内存或宿主时间。

沿用当前 C++20 编译参数、无宿主导入 WASM、64 MiB 内存、1 MiB 源码、8 MiB WASM 上限。初始化及输入指针调用共享 10,000,000 fuel；每步独立补足 20,000,000 fuel，不结转。输入拷贝不计入 Bot fuel，解码器和搜索计入。fuel 不等于毫秒。

## 二进制协议

沿用 `arena_init`、`arena_input_ptr`、`arena_tick` 导出签名和 64 KiB 输入缓冲。输入固定为 273 字节，由 48 字节头部和 225 字节棋盘数组组成。头字段为 12 个小端 uint32，按顺序为：

`magic=0x314d4f47`、`protocol_version=1`、`width=15`、`height=15`、`self_id`、`self_color`、`turn_color`、`move_count`、`last_x`、`last_y`、`move_fuel=20000000`、`win_length=5`。

空棋盘的 last_x / last_y 为 `0xffffffff`。棋盘按 `y*15+x` 排列。SDK 将合法坐标编码为 `y*15+x`（0～224）；225 表示认输；其余值为非法动作。包装器拒绝其他游戏的状态协议。

## 两盘换色与榜单

一次 Bot 对战生成两盘独立记录，在同一个计算任务中顺序执行。第一盘按选择顺序执黑、白，第二盘交换；开局种子保持一致，各 Bot 保留首盘的初始化种子。允许同一个 Bot 自我对弈。

每盘胜 1、平 0.5、负 0 分。显示两盘总比分；榜单按基准固定为 0 的实力分降序，同分并列，另列平均得分及执黑和执白平均分。只有两盘状态均为 `completed`、世界校验通过、结果有效且都未进入回收站时，整组参与统计。删除任意一盘使整组退出统计，恢复后重算。自我对弈按独立槽位累计。

第二盘失败或服务中断时保留已完成录像，整组不计分；重赛从原冻结输入建立新的两盘记录，无断点恢复。

## 录像与复现

人机模式使用相同规则，固定空棋盘单盘，可选择执黑或执白。人类输入先检查轮次与空位，合法动作才进入结算。等待输入不消耗 Bot fuel，Bot 内存和随机状态在盘内保留。人机对局不创建换色组、不计入榜单。

人机录像 header 增加 `mode=human`、`human_slot`；该槽位 entrant 标记 `kind=human`、`wasm_sha256=null`，初始化和动作 fuel 为 0，动作无 Bot 故障。世界校验仍逐步验证全部状态与终局，并拒绝非法人类动作。人机录像只提供世界校验，不支持要求双方 WASM 的 Bot 重跑校验。

每盘保存游戏 ID、规则、开局、参赛槽位、各 Bot 的 WASM 哈希和种子、预算、初始化、每步调用、落子、事件、状态哈希和终局。第 0 帧为初始化后的开局，第 k+1 帧为第 k 次调用结算后状态；预置三手属于初始帧，不计为 Bot 调用。

播放器只消费确认帧，支持逐手、时间轴、倍速、末尾结果、两盘切换、落子编号及获胜连线。世界校验重新生成开局并逐步结算；Bot 校验另需相同源码 / 工具链版本和原 WASM。不同游戏独立筛选和计分，缺少游戏 ID 的历史记录按炸弹人解释。

公开练习使用[五子棋开局清单](../../configs/gomoku-public-dev.json)，基准程序见[基准 Bot 源码](../../bots/gomoku/baseline.cpp)。
